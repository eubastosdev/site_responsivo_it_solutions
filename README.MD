# IT Solutions — Website Responsivo

Website institucional desenvolvido com **HTML5, CSS3, JavaScript e jQuery**, como projeto prático de estudos em desenvolvimento Front-End.

O projeto foi construído acompanhando uma videoaula de **Felipe Rocha, do Full Stack Club**, com o objetivo de aprimorar conhecimentos em desenvolvimento web, criação de interfaces modernas, responsividade e interatividade.

## Tecnologias utilizadas

- **HTML5** — estruturação semântica das páginas.
- **CSS3** — estilização e construção da interface.
- **JavaScript** — implementação de comportamentos dinâmicos.
- **jQuery** — biblioteca JavaScript para manipulação do DOM e interatividade.
- **Flexbox** — alinhamento e distribuição dos elementos.
- **CSS Grid** — organização de layouts em colunas.
- **Media Queries** — adaptação da interface a diferentes dispositivos.
- **Google Fonts** — tipografia Roboto.
- **Font Awesome** — utilização de ícones.

## Funcionalidades e seções

O website é composto por:

- **Navbar:** menu de navegação com identificação da empresa.
- **Showcase:** seção principal com imagem de fundo, título, descrição e botão.
- **Nossos Clientes:** apresentação de logotipos de empresas.
- **O que Fazemos:** seção dedicada aos serviços e soluções.
- **Nosso Produto:** apresentação do produto e suas funcionalidades.
- **Depoimentos:** avaliações ilustrativas de clientes.
- **Galeria:** organização de imagens em layout visual.
- **Rodapé:** informações institucionais e direitos autorais.

## Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/Eubastosdev/SEU-REPOSITORIO.git
```

### 2. Acessar a pasta

```bash
cd SEU-REPOSITÓRIO
```

### 3. Executar localmente

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no Visual Studio Code.

Não é necessário instalar Node.js ou executar `npm install` para utilizar o projeto.

**Observação:** bibliotecas carregadas por CDN, como jQuery e Font Awesome, podem exigir conexão com a internet.

## Conceitos desenvolvidos

Durante o projeto, foram praticados conceitos fundamentais de desenvolvimento web:

- Estruturação de páginas com HTML semântico.
- Utilização de classes e identificadores CSS.
- Box Model: `margin`, `padding` e `box-sizing`.
- Posicionamento e alinhamento com Flexbox.
- Organização de layouts com CSS Grid.
- Responsividade com media queries.
- Imagens de fundo e efeitos de sobreposição.
- Pseudoclasses e transições.
- Separação entre estrutura, apresentação e comportamento.
- Utilização de JavaScript e jQuery.
- Organização de arquivos em diretórios.

## Responsividade

O projeto utiliza uma estrutura de estilos separada para facilitar a manutenção:

- `style.css` — estilos gerais da aplicação.
- `mobile.css` — adaptações para telas menores.

O objetivo é proporcionar uma experiência de navegação adequada em computadores, tablets e smartphones.

## Objetivo do projeto

O desenvolvimento do IT Solutions faz parte da minha jornada de aprendizado em programação e desenvolvimento Full Stack.

O foco é consolidar os fundamentos do Front-End, compreender a construção de interfaces responsivas e desenvolver boas práticas de organização de código.
